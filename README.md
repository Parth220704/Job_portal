# CareerBridge – Intelligent Job Portal

CareerBridge is a full-stack MERN-based job portal that connects job seekers and recruiters through a centralized recruitment platform. The system goes beyond traditional job portals by providing intelligent job matching, skill gap analysis, learning recommendations, and priority-based job notifications.

The platform supports three user roles: **Admin**, **Recruiter**, and **Job Seeker**. Recruiters can create company profiles, post and manage job vacancies, review applications, and shortlist candidates. Job seekers can build professional profiles, upload resumes, search and apply for jobs, track application status, and receive personalized job recommendations based on their skills and experience.

### Key Features

* Role-Based Authentication (Admin, Recruiter, Job Seeker)
* Secure User Registration & Login
* Company Profile Management
* Job Posting & Job Management
* Advanced Job Search & Filtering
* Resume Upload (PDF)
* Online Job Applications
* Application Tracking System
* Recruiter Dashboard
* Admin Dashboard & Analytics
* Intelligent Job Recommendation System
* Skill Gap Analysis
* Learning Resource Suggestions
* Job Match Percentage Calculation
* Priority Job Notifications Based on Expiry Dates
* Recruiter Approval & User Management

### Technology Stack

**Backend**

* MongoDB

### Project Goal

CareerBridge aims to improve recruitment efficiency by helping job seekers discover suitable opportunities while enabling recruiters to find qualified candidates faster through intelligent skill-based matching and recommendation features.

This project was developed as an MCA Software Project under the domain of Online Recruitment Systems.
